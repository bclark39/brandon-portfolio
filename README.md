# Brandon Clark — Interactive Portfolio

A modern, dark‑mode, neon‑accented interactive portfolio for **Brandon Clark**, showcasing experience, skills, and contact options.

## 🚀 Features
- Dark‑mode UI with minimal neon cyan accents  
- Expandable/collapsible experience sections  
- Interactive skill tags  
- Smooth, responsive layout  
- Collapsible contact form  
- Clean, modular code (HTML, CSS, JS)
